# Getting help

1. **Run the doctor first.** `angaros doctor` checks the relay, the pairing, how
   recently the phone checked in, the background daemon and the default SIM, and
   prints a fix for every problem it finds.
2. **Read the troubleshooting guide:** [docs/troubleshooting.md](docs/troubleshooting.md).
3. **Search the [issues](https://github.com/Mahdi-mortazavi/angaros/issues)**,
   then open a [bug report](https://github.com/Mahdi-mortazavi/angaros/issues/new?template=bug_report.yml)
   with the doctor output. The app's *Settings → Diagnostics* report contains no
   messages and no keys, so it is safe to attach.
4. **Questions and ideas:** [GitHub Discussions](https://github.com/Mahdi-mortazavi/angaros/discussions),
   or the [Startup Legend](https://t.me/Startup_legend) community on Telegram
   (English and Persian).

Never post a `pb1:` pairing string, `config.json`, `api_token`, a Worker URL or
real message text. Security problems go through [SECURITY.md](SECURITY.md), not
public issues.
